# Roskins: original placeholder illustrations

Twelve standalone 160 × 160 SVG illustrations, created specifically for the Roskins Trade Plaza prototype using original vector paths and gradients. Transparent backgrounds, no external dependencies, fonts, scripts, remote images or paid resources. Each SVG includes an accessible title.

These are **original, stylized, illustrative placeholders**. They are not official Roblox or Adopt Me assets, screenshots, item renders, or exact representations of in-game items. Item names are only used to identify the intended catalogue category. Replace or clearly label these illustrations before presenting them as authoritative inventory imagery.

Files: `turtle.svg`, `unicorn.svg`, `frost-dragon.svg`, `shadow-dragon.svg`, `kangaroo.svg`, `owl.svg`, `cow.svg`, `arctic-reindeer.svg`, `bat-dragon.svg`, `ride-potion.svg`, `fly-potion.svg`, `egg.svg`.

`generate.py` regenerates the SVG files locally with Python's standard library. No network access is needed.
